# BugBounty Recon Workflow - Mxm

Herramienta/colección de scripts para automatizar reconocimiento inicial en programas de bug bounty.

## Objetivo
Automatizar discovery: subdominios, hosts vivos, directorios, plantillas nuclei y escaneos básicos.

## Requisitos
- Linux/WSL/Ubuntu
- subfinder
- httpx
- nuclei
- nmap
- jq
- ffuf (opcional)
